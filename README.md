# הרפתקת הסתברות

אתר אינטראקטיבי לילדים בגילאי 10-12 ללימוד עקרונות הסתברות.

## מה יש באתר
- הסבר קצר וברור על סוגי הסתברות (בטוח, אפשרי, בלתי אפשרי)
- מעבדת ניסויים אינטראקטיבית: מטבע, קובייה, גלגל הסתברות לא שווה
- אתגר שאלות מהיר עם רצף הצלחות
- מצב פוקוס להפחתת עומס חזותי ולמידה ממוקדת
- עיצוב מותאם לנייד ולדסקטופ

## הרצה מקומית
פותחים את `index.html` בדפדפן.

## פריסה ב-GitHub Pages
האתר מוגש מענף `gh-pages` מה-root של הריפו.
